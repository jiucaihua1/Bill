# 小禾记账产品文档

逐项验证见 [验收清单](acceptance-checklist.md)，源码分层和数据口径见 [架构导览](../dev/architecture.md) 与 [技术决策](../dev/tech-decisions.md)。

## 产品定位

小禾记账是一款完全免费、数据自主、本地优先的 Android 记账应用。它不要求账号，不依赖自有服务端，不投放广告，也不接入广告或统计遥测 SDK。权威账目数据保存在用户设备；只有用户主动启用导出、WebDAV 备份或 AI 功能时，相关数据才会发送到用户选择的目标。

产品目标是提供一套可长期使用的个人记账、资产、预算和分析工具，同时保持数据可导出、功能可离线运行、关键操作由用户确认。

## 产品原则

- **本地优先**：账本、账户、交易、分类、标签、附件、周期规则和预算以本地 SQLite 为权威数据源。
- **用户控制**：偏好设置与已有实体编辑自动保存，返回不再要求二次确认；文本停止输入后提交，失败时保留页面状态并提示。新建交易、还款、退款、导入、恢复、初始化、删除和 AI 记账等高影响操作仍必须经过明确的创建/确认或预览；AI 与外部采集入口绝不静默落账。
- **隐私优先**：应用不监听通知、屏幕、无障碍或短信。截图在端上 OCR，原图不上传；使用远程 AI 时只把必要文本或账目摘要发往用户配置的端点。
- **可迁移**：支持手动/自动备份、本地目录、加密、WebDAV 和旧备份兼容，避免数据被锁在应用中。
- **Android 优先**：只正式交付 Android；所有文件、权限、通知、小组件、分享与安装能力都必须有真实原生实现。

## 信息架构

底部导航从左到右依次为首页、看板、资产、我的。默认使用液态玻璃，可在「设置 → 外观 → 导航栏样式」切换为停靠底栏。

- **首页**提供快速记账、可配置的近七天概览、近期交易、预算提醒和日历。
- **看板**按周、月、年查看历史收支、分类和标签排行，可调整面板顺序并进入 AI 账目问答。
- **资产**集中查看账户、净资产、信用账户和余额趋势，可按类型或自定义分组。
- **我的**显示记账年数与交易笔数，并提供记账管理、订阅支出、数据管理、桌面小组件和设置。设置里的「鸣谢」展示项目署名，「更多」打开 Bill 仓库或检查更新。

## 核心流程

### 记账

首页「记一笔」支持三种行为：手动记账、AI 记账、点击手动/长按 AI。手动入口先打开支持四则运算的数字键盘，再进入记账详情页；详情页支持支出、收入、转账、金额、分类、标签、账户/无账户、转入账户、手续费、备注、日期时间和图片附件。

默认付款账户按账本保存。记账自动识别会根据用户自己的历史推断支出/收入类型、分类、标签和备注，可在设置中全局关闭；AI 草稿和导入草稿不启用自动识别。

AI 记账、截图识账、系统分享和自动化 Intent 都生成待确认草稿。截图文字先在本机识别，再交给用户配置的 OpenAI 兼容端点。支出截图按「支付方式」或「付款方式」匹配账本里的账户，例如微信零钱匹配微信支付，余额宝匹配支付宝。只能匹配到账本中唯一账户时才预选，待用户核对并保存。

AI 设置可选择 8 个内置 OpenAI-compatible 渠道或自定义端点。预设渠道的 Base URL 固定只读，切换渠道会清空旧 API Key 与模型；API Key 允许留空，模型可从渠道远端列表选择或手动填写。模型发现只发送渠道鉴权与固定请求头，不包含账目或聊天内容。

### 多币种与离线汇率

每个账本有一个本位币，预算、首页、看板、统计和 AI 汇总统一使用该币种；每个账户只持有一种账户币种，余额、初始余额、额度和手续费始终按账户币种计算。普通交易分别保存原币金额、账户真实扣入账金额和记账时冻结的本位币金额，跨币转账保存转出、转入两端的实际金额。账户或账本存在财务数据后币种锁定，旧账本只允许一次「数字不变、重新确认币种」的重解释。

汇率按账本、外币和生效日保存在 SQLite，方向固定为 `1 外币 = X 本位币`，只使用交易日或更早的最近记录。应用不会联网下载或后台刷新汇率；修改或删除汇率不重算已保存交易，只影响以后录入、周期补记和资产估值。缺少必要汇率时不按 1:1 猜测：交易要求补齐实际金额或汇率，资产总额则显示缺率状态而不是部分和。

金额单位默认使用符号后置（如 `100 ¥`），也可在设置中切换为代码前置（如 `CNY 100`）。单币种账本默认隐藏重复的单位——不只是金额旁，页头副标题与卡片角标也不再标出币种，连 AI 助手的回答里都不出现币种代码（可以在设置里关闭这个开关）；多币种账本的账户与交易金额始终保留单位。界面汇率使用可读的自适应小数位，只缩短展示，不降低保存或导出精度。

### 交易、报销与退款

交易列表支持日期分组、搜索、多维筛选、排序和批量改分类/账户/删除。「收支」筛选菜单包含预算和收支口径，可与账户、分类等条件一起使用。批量改账户只允许原账户币种一致且已有实际账户金额的交易，跨币种、无账户或转入冲突必须逐笔编辑。转账只影响账户余额，不计入收支统计，手续费由转出账户承担。

支出可标记待报销。收到退款后，在原支出详情记录金额、到账账户、日期和备注，支持多笔和跨账户退款。旧数据和导入中的待到账记录可在原支出确认到账或删除。只有已到账退款影响余额和支出净额。交易详情把本体、退款和附件作为一个聚合自动保存，有效改动立即原子提交，校验失败在页内提示。

### 预算与分析

预算支持默认月预算、总预算与分类预算的单期覆盖、分类默认预算、按日花销上限，以及每账本独立的预算周期起始日。`BudgetOverviewPage` 用于查看当前/历史预算状态，并管理所选月份/周期的总预算和分类预算覆盖；`BudgetSettingsPage` 集中编辑默认值、周期和分类默认预算。只有预算体系按自定义周期聚合，统计报表仍按自然月。

首页概览曲线显示含今天在内的连续七个自然日。点开可看每日收支明细，也可以切换自然周、月、季或年。概览的可选指标包含近七天收入、支出和结余。看板默认显示本周，周一到周日为一个自然周。周、月、年均可步进、选择历史期间和回到本期。周统计提供收支摘要、每日收支柱图与日均、分类占比和分类及标签排行，本周还可查看当前资产汇总。月统计提供收支摘要、预算执行、分类占比、排行与日趋势。周、月的走势图及分类占比都支持切换收入和支出。年统计展示全年摘要、逐月收支双柱、热力图与排行。排行下钻沿用所选期间。

AI 账目问答以只读财务 Agent 运行：Composer 的账本选择器可选择本次对话使用的账本（默认当前账本），切换账本只影响之后的问题，不改变应用全局活动账本。Agent 可通过原生 Tool Calls 或兼容标记协议自主查询所选账本，并以统计卡、柱状图、折线图、只读交易列表、表格和 Markdown 作答；聊天页会展示可展开的工具调用步骤，但不展示模型推理、原始工具 JSON 或底层异常。每条回答标明是否实际查询账本及查询次数；零工具调用却给出金额时明确提示结果未经账本验证。正文流式显示，发送按钮在请求期间切换为停止按钮；对话只保留在当前页面，离开即清空，顶部可随时清空当前对话，不进备份。未配置 AI 时显示空状态插画和前往配置入口。AI 工具不能修改任何数据。

支出分类明细显示所选期间的总支出和平均每笔支出。时间菜单提供全部、本周、本月、本年和自定义起止日期。

### 订阅支出

在「我的 → 数据与工具 → 订阅支出」可以查看当前账本的会员和订阅。应用按备注识别订阅，也可在右上角从已有支出手动选入。付款周期按月数填写，例如月付填 1、季付填 3、年付填 12。

「今日日均花费」把每笔订阅的退款后实付金额按实际有效天数分摊，只计今天仍有效且已设置周期的订阅。点开可查看参与分摊的项目、日期和金额。

### 资产与信用账户

账户可按类型或自定义分组展示，并支持账户币种、计入资产、隐藏、排序、图标、完整卡号/后四位和账户备注。账户行保留原币余额，净资产和历史走势完整折算到当前账本本位币；缺任一必要汇率时不显示不完整总额。资产页分区展开/折叠按账本与视图模式持久化，视图模式、背景和排序集中在「资产显示设置」中，修改即自动保存。账户类型包括网络支付、信用账户、信用卡、储蓄卡、投资账户和现金。

信用卡与信用账户支持额度、账单日、还款日、已用/可用额度、本期账单与还款。还款本质是一笔使用转账分类的转账；扣款账户可为空表示他人代还。余额调整通过生成差额交易表达，不直接覆盖历史流水。

## 数据、备份与安全

### 存储分层

- SQLite：账本及本位币、交易三层金额、账户及币种、按日汇率、账户分组、分类、标签、附件、周期规则、月度/分类/按日预算。
- SharedPreferences/KV：主题、语言、触感、页面配置、资产排序、默认账户、预算周期、自动识别开关、AI/备份/提醒/应用锁等偏好。
- Controller 内存集合是运行时读取源，但真实平台不能以内存实现代替持久化。

SQLite repository 的 `saveX` 对外保持“传入集合即最终表状态”的语义；生产实现对主要账目表做行级差分写入，并把“计算差分、事务写入、更新快照”整体串行化。附件表只保存元数据（图片字节是应用私有目录下的独立文件，由 `AttachmentStore` 统一读写），与小型预算表一样可整表覆盖；旧库升级期间该表还留着尚未转换的 `data_url` 列，所有写入路径（含整账本原子整替）都必须保留它，转换完成后才去列回收。交易详情通过单个事务原子保存交易/退款和附件元数据，导入、恢复、重置、删账本及跨表删除等操作使用原子整替，成功后才提交 Controller 内存状态。

### 备份格式与范围

未加密备份为 zip：`backup.json` 加独立的 `attachments/<id>` 文件；加密备份为 AES-GCM + PBKDF2 保护的流式加密容器（`.verifin`，密文里是同一个 zip）。导入可自动识别 zip、加密容器、旧版 JSON 加密信封和旧版明文 JSON。打包、加密、写入、校验、解包全程流式并显示阶段进度，可中途取消；写入后用流式 SHA-256 校验，写坏或文件损坏会明确提示。

JSON v4 备份包含账本本位币和确认状态、账户币种、交易各端金额和转换来源、周期汇率策略、汇率表、按账本保存的分类与标签、全部既有账目数据与显示偏好；v1/v2/v3 旧备份继续兼容，数字原样载入为待用户确认的 CNY，旧备份里全局共享的分类/标签在导入时按账本各展开一份。应用锁哈希、备份口令、WebDAV/AI 凭证、语言、导航样式、提醒、备份目录、日志和桌面小组件实例配置等保持设备本地，不进入备份。

第三方账单导入支持支付宝、微信、薄荷、一木、钱迹、随手记、Tally 和本应用 CSV 模板。随手记导出的多工作表 xlsx 会按工作表导入支出、收入、转账和退款：退款因没有原支出编号按收入兜底；余额变更按差额记入「余额调整」；债务/借贷与负债变更不导入。用户先选择来源，解析后进入零副作用预览，可排除/编辑交易并映射账户、分类、标签，确认后才落库。本应用 CSV 导出保留原币、账户/转入账户币种、两端实际金额、本位币金额和派生汇率；退款按独立行保留原支出关联、待到账状态、到账账户与发起/到账日期；外币缺率可在预览前手工补齐，导入汇率默认不写汇率表，只有用户明确开启后才随最终保留的交易保存。

### 导入与云备份

导入账单时先选来源，再预览交易、账户和分类的匹配结果。「检查重复导入」比较当前账本中除内部 ID 外字段都相同的导入交易，确认后才清理可删除的副本。有关联退款或附件的原交易受保护。

在「我的 → 数据管理 → WebDAV 服务器」可配置自定义地址。使用坚果云时可一键填入默认的 `Bill` 目录，账号填写注册邮箱，密码填写第三方应用密码。连接测试会尝试创建缺失的目标目录。保存后可手动上传、恢复远端备份，也可让自动备份完成时一并上传。

### 应用安全

应用锁支持 6 位 PIN、3×3 图案和系统生物识别。锁配置只保存加盐哈希，不保存明文密码或生物特征；启用应用锁后使用 `FLAG_SECURE` 隐藏截图和最近任务缩略图。密钥无法找回，因此锁屏页提供「忘记密码」出口：两步破坏性确认后清空全部本地账目并关闭应用锁（含生物识别），这是忘记密钥时唯一能恢复使用的路径。

Android Manifest 明确禁用系统 Auto Backup；账目、AI/WebDAV 凭据、备份口令和应用锁配置不会由应用默认参与系统云备份。跨设备迁移使用应用内导出/恢复或用户主动配置的 WebDAV。

**只推荐应用内的备份**（数据管理 → 立即备份 / 导出为文件）。不推荐用系统备份、应用数据备份、换机搬家类工具或第三方备份 App 来备份/还原本应用数据：它们绕过本应用的备份格式与校验，直接搬运应用私有数据，容易搬出半截或损坏的文件；**这类方式造成的数据损坏或丢失，应用方无能为力，也无法修复**。小米「应用数据备份」等产物的格式（如 `VeriFin(top.talyra42.verifin).bak`）不是本应用的备份，应用内无法导入。

本地日志只保存在设备，用户可查看、复制或清除；应用不做远程崩溃或行为遥测。

## Android 系统能力

- 系统下拉快捷磁贴打开快速记账。
- 系统分享图片/文本和显式 `CAPTURE_TEXT` Intent 进入待确认识账流程；分享图片按流读取并在超过 25 MB 时立即拒绝。
- 桌面小组件支持快速记账、预算进度、收支趋势、净资产和双栏收支五类模板。每个实例可独立选择账本、外观和点击后的入口，双栏收支可分别选择左右指标。未配置的组件只显示一行「点击进入配置」，点击即进入配置页；应用内页面与系统选择器都展示原生渲染的预览。
- 每日记账提醒、本地通知测试和回前台重排。
- Android SAF 备份目录、系统 Downloads 导出和文件导入。
- GitHub flavor 提供应用内「检查更新」：只查询 GitHub Release 的最新正式版版本号，发现新版本后由用户点「前往」用系统浏览器打开该版本的 Release 页面；应用不下载、不安装 APK，也不申请安装未知应用权限。Play flavor 由商店负责更新，并隐藏检查更新入口。

平台能力必须覆盖冷启动、回前台、进程被杀、重启/升级、权限拒绝和 Doze 等场景。正式验收使用个人版证书签名的 release APK。

## 视觉与国际化

界面方向是紧凑型移动端金融工具：较高信息密度、小圆角、轻阴影、统一 Header 和 4/8pt 间距节奏。主交互色为 `#346edb`，辅助蓝为 `#3498db`，青绿色只用于收入和正向状态；金额为零显示中性色 `0`，不出现 `-0`。

触感反馈统一为选择、轻动作、命令成功与破坏性四档语义，覆盖底栏切页、分段选择、期间步进、选择器确认、图表点选、日历、拖动排序、数字键盘、开关与显式命令的结果；可在「设置 → 通用 → 触感反馈」关闭，关闭后全应用不再震动（包括长按与拖动排序）。

应用支持跟随系统、简体中文和 English。用户可见文案通过 Flutter gen-l10n 管理；系统日期/时间选择器、通知、小组件和生物识别提示都应跟随应用语言。种子账本和分类按首次创建时的语言生成，之后属于用户数据，不随语言切换自动改名。

## 当前边界

- 不提供账号体系、实时云同步或多端协作；WebDAV 只用于用户主动配置的备份/恢复。
- 不提供在线汇率、后台行情刷新、加密货币、自定义商品货币或汇兑损益核算；法币目录与汇率操作均离线。
- 不做通知监听、无障碍监听、短信读取或后台静默记账。
- 手动记账支持账户间转账，并可通过应付款账户借入、应收款账户借出。借贷本金按两端账户余额变动记录，归在转账口径。资产页的债务金额汇总计入资产的应付款和信用账户欠款，点击金额可进入应收款、应付款和信用欠款明细。第三方债务记录暂未支持导入。
- 暂无项目和商家管理。
- 当前不提供批量报销/批量退款；待报销交易逐笔在交易详情处理。
- Bill 通过 GitHub Releases 发布面向 arm64 Android 设备的 APK。
- 当前不提供 Unsplash API 搜索图库，只支持内置线上图、自定义链接和本地图片。

## 技术结构

- `lib/main.dart`：初始化与根生命周期。
- `lib/app/veri_fin_controller*.dart` + `VeriFinScope`：单一应用状态源。
- `lib/pages/`：页面与交互流程。
- `lib/data/`：SQLite schema、迁移和 repository。
- `lib/local_storage/`：设备偏好 KV。
- `lib/app/backup/`、`lib/app/ai/`、`lib/app/reminder/`、`lib/app/logging/`：领域子系统。
- `android/`：MethodChannel、SAF、更新、分享、通知、小组件和双 flavor 配置。

开发命令、组件复用、测试、文档和发布规则见根目录 `AGENTS.md`。
