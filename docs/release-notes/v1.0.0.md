## 本版变化

- 小禾记账个人版从 `1.0.0` 开始编号，Android 安装 ID 为 `com.xiaohe.ledger`。
- 微信支付结果和账单详情合并为一笔记账提示。详情匹配成功时，商品名补入原备注。
- 自动记账常驻通知可在重新打开应用时恢复，今日净支出随首页的数据和退款变化刷新。

## 安装与迁移

已使用 `com.xiaohe.ledger` 的用户可覆盖安装此 APK。更新前可在「我的 → 数据管理」导出完整备份。

仍使用旧安装 ID `top.talyra42.verifin.personalledger` 的用户可并行安装新版。在旧版导出完整备份，在新版恢复并核对账本和图片附件。使用自动记账或桌面小组件时，请在新版重新授权和配置。
