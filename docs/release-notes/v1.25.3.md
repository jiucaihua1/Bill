## 本版变化

- 快速记账切换分类时，重新从新分类的历史账单匹配备注。无匹配时清空自动备注，手动编辑或清空的备注随本笔草稿保留。
- 修复手动记账、自动记账与批量改账户同时操作时，流水或账户修改可能被覆盖的问题。批量保存失败后可保留原数据和选中项重试。
- 本地目录和 WebDAV 分别显示上次成功备份时间。备份过程中新增的流水会合并到下一轮自动备份。
- 自动记账通知可重新打开尚未确认的草稿。成功入账或取消后清理对应通知。

## 安装与更新

已安装相同签名的小禾记账（`com.xiaohe.ledger`）可下载本页的 APK 覆盖更新。更新前可在「我的 → 数据管理」导出备份。

如果从旧包名 `top.talyra42.verifin.personalledger` 迁移，请先在旧版导出完整备份，再安装新版并恢复。
