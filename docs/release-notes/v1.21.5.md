# 小禾记账个人版 1.21.5

- 微信和支付宝付款可生成待确认账单。支付宝优先读取付款成功页控件，支持账单详情补记，首页旧付款消息不会生成新账单。
- 支付宝交易提醒和建设银行动账提醒可以补记。同一笔支付宝付款已识别时，后到的建行通知会去重。
- 确认保存后，常驻通知自动更新今日支出。能识别到的商户或收款方会填入备注，付款账户可按银行卡尾号匹配。
- 手动记账合并日期与时间入口。手动和自动记账均可填写优惠，余额和报表按实付金额计算。

## 安装与更新

在小禾记账打开「我的 → 设置 → 更多 → 检查更新」，或下载本页的 arm64 APK。打开 APK 后按 Android 提示覆盖安装，保留现有账本。
