## 本版变化

- 看板的周、月、年收支摘要可打开对应期间的交易明细。月收支卡加入日历，周柱状图联动每日收支，年度热力图可预览每日金额并跳转到指定月份。
- 首页右上角可搜索交易。明细默认看本年，分类子项默认折叠。收到退款后可从原支出登记，旧待到账记录也可在原支出确认到账或删除。
- 记账属性栏支持横滑。单笔详情依次显示备注、标签、统计与报销开关。转账和债务的账户行显示各自余额。
- 改善备注输入法与数字键盘的衔接，修复返回退出提示残留和移动分类保存失败。
- 桌面小组件支持背景透明度、字号、对齐和文字颜色。外部联网默认关闭，手动 WebDAV 操作可按服务器单次授权。

## 安装与更新

使用相同签名的小禾记账（`com.xiaohe.ledger`）可覆盖安装并保留原账本。更新前可在「我的 → 数据管理」导出备份。
