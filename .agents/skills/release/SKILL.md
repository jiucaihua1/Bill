按 [README](../../../README.md#下载) 构建并发布 Bill 的 Android 个人版。

- 从 Bill 的 main 核对版本号、CHANGELOG 和发布说明。
- 使用现有个人版签名和 README 中的构建命令。检查 APK 包名和签名，并在手机验证覆盖安装。
- 发布到 Bill 的对应版本 Release，附签名 APK，核对 Latest 和应用内检查更新。
